  هلدینگ گیتی‌پسند — وب‌سایت شرکتی
=====================================================

هیچ نصبی لازم نیست! نه npm، نه Node.js، نه هیچ برنامه‌ی دیگری.

──────────────────────────────────────
  چطور بازش کنم؟
──────────────────────────────────────

راه ۱ (ساده‌ترین):
  روی فایل "index.html" دوبار کلیک کنید. همین!
  در مرورگر پیش‌فرض (Chrome، Edge و...) باز می‌شود.

راه ۲ (برای بهترین نتیجه — پیشنهادی):
  بعضی مرورگرها هنگام باز کردن مستقیم فایل، برخی جلوه‌ها را
  محدود می‌کنند. اگر خواستید حتماً همه‌چیز کامل کار کند:
  1. پوشه‌ی این پروژه را باز کنید
  2. توی نوار آدرس بالای File Explorer کلیک کنید
  3. بنویسید cmd و اینتر بزنید
  4. در پنجره‌ی سیاه‌رنگی که باز می‌شود بنویسید:
       python -m http.server 8000
     (اگر پایتون نصب ندارید، همان راه ۱ کاملاً کافی است)
  5. در مرورگر بروید به آدرس: http://localhost:8000

نکته: برای انیمیشن‌ها (GSAP) اتصال اینترنت لازم است چون از یک
سرویس آنلاین (CDN) بارگذاری می‌شوند — نه نصب برنامه، فقط اینترنت
معمولی مرورگر. اگر اینترنت نبود، سایت باز هم کامل کار می‌کند،
فقط بعضی جلوه‌های حرکتی (تیلت کارت‌ها، شمارنده‌ی انیمیشنی و...)
غیرفعال می‌شوند و مستقیماً حالت نهایی نمایش داده می‌شود.

──────────────────────────────────────
  ساختار فایل‌ها
──────────────────────────────────────
index.html          → خود صفحه (این را باز کنید)
css/style.css        → استایل‌ها
js/main.js            → جلوه‌ها و تعامل‌ها
assets/gallery/       → ۱۲ تصویر باکیفیت از فیلم پروژه (گالری)
assets/bg/            → تصاویر پس‌زمینه‌ی هیرو و بخش‌های دیگر
assets/team/           → اینجا عکس پرسنل را اضافه می‌کنید (پایین را ببینید)

──────────────────────────────────────
  اضافه‌کردن عکس هیئت‌مدیره
──────────────────────────────────────
داخل پوشه‌ی assets/team عکس‌ها را با همین نام‌ها کپی کنید:

  babak.jpg     → مهندس بابک انتظاری (رئیس هیئت‌مدیره)
  ali.jpg       → مهندس علی کاملیان (مدیرعامل)
  shiravi.jpg   → مهندس شیروی (طراح معماری پروژه)

همین! صفحه را رفرش کنید، عکس‌ها خودکار جای مونوگرام‌ها می‌نشینند.
(فرمت jpg یا png هر دو کار می‌کنند، فقط اسم فایل را می‌توانید
در همین پوشه، فایل INSTRUCTIONS.txt هم دوباره یادآوری کرده.)

⚠️ چون من (دستیار) به عکس واقعی این افراد دسترسی نداشتم، فعلاً یک
مونوگرام (حرف اول اسم روی زمینه‌ی بلوپرینت) به‌جای عکس گذاشته شده —
نه عکس واقعی و نه تصویر ساخته‌شده با هوش مصنوعی از چهره‌ی کسی.

──────────────────────────────────────
  ویرایش متن‌ها و اطلاعات تماس
──────────────────────────────────────
فایل index.html را با Notepad (یا هر ویرایشگر متن) باز کنید و
دنبال این بخش‌ها بگردید:

- ایمیل نمونه: info@gitipasand.example  → با ایمیل واقعی جایگزین کنید
- شماره‌ی نمونه: 982100000000+  → با شماره‌ی واقعی جایگزین کنید
- آمار (۱۴ سال تجربه، ۸۶ پروژه و...) → با data-count="عدد واقعی" عوض کنید

──────────────────────────────────────
  چه چیزهایی توی این سایت هست
──────────────────────────────────────
✓ هیرو با پس‌زمینه‌ی سینمایی و افکت زوم آرام (Ken Burns)
✓ نوار متحرک خدمات (marquee)
✓ آمار متحرک (شمارنده‌ی اعداد هنگام اسکرول)
✓ بخش «درباره‌ی ما» با پارالاکس تصویر
✓ ۶ کارت خدمات با افکت سه‌بعدی (tilt) هنگام هاور
✓ گالری/آلبوم ۱۲ تصویری از سکانس‌های باکیفیت فیلم پروژه، با کلیک
  روی هر عکس، بزرگ‌نمایی (لایت‌باکس) با دکمه‌ی بعدی/قبلی باز می‌شود
✓ بخش تیم مدیریت با کارت پرسنل
✓ دکمه‌های مغناطیسی (کمی به‌سمت اشاره‌گر ماوس کشیده می‌شوند)
✓ نشانگر ماوس اختصاصی (روی دسکتاپ)
✓ کاملاً واکنش‌گرا برای موبایل و تبلت، با منوی همبرگری
✓ پشتیبانی از prefers-reduced-motion (برای کاربرانی که حرکت کم
  ترجیح می‌دهند، انیمیشن‌ها به‌طور خودکار کاهش می‌یابند)

هیچ ویدیویی پخش نمی‌شود و هیچ موسیقی‌ای وجود ندارد — طبق درخواست شما،
این نسخه فقط از تصاویر ثابتِ باکیفیتِ برگرفته از فیلم استفاده می‌کند.

──────────────────────────────────────
  اگر خواستید تصاویر گالری را عوض کنید
──────────────────────────────────────
در فایل js/main.js، بالای فایل، آرایه‌ی galleryItems را پیدا کنید؛
هر آیتم یک src (مسیر تصویر) و caption (زیرنویس) دارد. کافی است
تصویر جدید را در assets/gallery بگذارید و مسیرش را اینجا بنویسید.
